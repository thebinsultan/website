# Picks Nest — Discovery-first homepage

A responsive, static redesign inspired by [picksnest.com](https://picksnest.com/). The homepage turns the existing product articles into an easier-to-browse directory with category filters, live search, sorting, quick-look dialogs, and locally saved picks. Built with plain HTML, CSS, and JavaScript; no build step or package installation is required.

## Run locally

```sh
python3 -m http.server 5173 --bind 0.0.0.0
```

Open `http://localhost:5173`. Product photography and product-guide links use the original Picks Nest site. The design intentionally links shoppers to the existing product guides rather than inventing prices or purchase links.
